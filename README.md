# clock-has-a-pomodoro-timer-and-a-speaker-connect-bluetooth-
Progessing - This is my smart clock which show time, pomodoro, a bluetooth speaker with play/pause , next song button and a potentiometer to control volume
98357a
component: ESP32, 3 LED, OLED 0.96 inch, poteniometer, maxa98357a, speaker and some regissters 220, 10K.

GPIO connect:
  3v3 - VDD
  GND - GND
  SCK - 22
  SDA - 21
  PLAY/PAUSE BUTTON - 14
  NEXT BUTTON - 33
  POMODORO BUTTON - 13
  RED LED - 18
  YELLOW LED - 19
  BLUE - 23
  POTENTIONMETER INPUT - 34
  Vin - VN
  LRC - 26
  BCLK - 27
  DIN - 25
